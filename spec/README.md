# ATOM v4 Canonical Specification

This directory is the normative source of truth for stable enums, requirements, invariants, state machines, schemas, acceptance tests, and compatibility profiles. Prose documents explain these contracts but MUST NOT redefine them inconsistently.

Precedence: schemas/state-machines/enums -> requirements/invariants -> ADR decisions -> PRD/Blueprint prose. Any contradiction is a specification defect that blocks release until resolved by ADR and spec update.
